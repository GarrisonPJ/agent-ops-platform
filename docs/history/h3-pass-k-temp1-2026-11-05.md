## What this shows

- **The endpoint pins a default sampler seed.** The installed llama.cpp
  service uses seed 42 unless a request sets one. A direct check sent the same
  chat request twice at temperature 1 without a `seed` field and got identical
  output; with `"seed":1` versus `"seed":2` the outputs differed.
- **So the reference Agent's trials were still copies.** Every reference group
  has one trajectory, and pass^5 equals pass^1, as at temperature 0.
- **pi's groups diverged on fault and order.** The likely cause is per-Run
  differences in pi's prompt, for example its private temporary paths. This is
  not verified, and it is not independent sampling.
- **Consequence.** Neither temperature 0 nor temperature 1 on this endpoint
  gives independent trials for identical requests. Independent trials need a
  varying sampler seed: a server started with a random seed, or a per-Run
  request seed. That option does not exist yet; it is an open decision.

## Limits

Eight groups of five on one model and one endpoint. This is not a pass rate,
not evidence about other models, and not analyzer accuracy (H5). The pi spread
must not be read as the chance of independent attempts succeeding. The
temperature-0 record is [h3-pass-k-live-2026-11-04.md](h3-pass-k-live-2026-11-04.md).
